\chapter{Literature Review and Related Work}
\label{ch:relatedworks}

\noindent
This chapter reviews related work relevant to prestimulus EEG-based behavioral prediction and to the software workflow required to run such experiments reproducibly. It first summarizes competing tools/workflows and then reviews foundational resources and key methodological insights that informed this project.
\vspace{1em}

\section{Competitor Analysis}
\label{sec:competitor-analysis}

Several existing tools support EEG preprocessing and modeling, but they differ in how directly they support a constrained prestimulus prediction setting (CCD-ITI) and how well they support end-to-end reproducible experimentation.

\begin{itemize}
    \item \textbf{MNE-Python / MNE-BIDS:} strong for EEG preprocessing and BIDS interoperability, but experiment tracking and UI-driven workflows are typically built by the user.
    \item \textbf{EEGLAB / Brainstorm:} mature GUI tools for analysis and visualization, but reproducible pipeline execution and code-centric experiment comparisons may require additional scripting.
    \item \textbf{General ML notebooks:} flexible and fast to prototype, but prone to fragmentation (hidden state, inconsistent preprocessing, unclear configurations) unless carefully standardized.
\end{itemize}

This project complements these tools by emphasizing a traceable workflow tailored to the CCD-ITI prestimulus window: consistent event parsing and trial alignment, standardized preprocessing and feature extraction, and repeatable evaluation for both RT regression and correctness classification.

\section{Literature Review}
\label{sec:literature-review}

\subsection{Foundational Works Leveraged}
\label{subsec:foundational-works}

The EEG Foundation Challenge (EEG2025) provides the Healthy Brain Network EEG (HBN-EEG) dataset as a large-scale, high-density, multi-task EEG resource. Importantly for reproducible research, the dataset is distributed in BIDS format with HED annotations, which standardize file organization and event labeling across recordings.\footnote{\cite{eeg_foundation_challenge_2025,hbn_fair_2024}.}

\begin{itemize}
    \item \textbf{HBN-EEG FAIR implementation (2024):} Presents analysis-ready EEG with integrated behavioral events and HED annotations, enabling reproducible analyses.\footnote{\cite{hbn_fair_2024}.}
    \item \textbf{HBN transdiagnostic resource (2017):} Describes the HBN biobank’s large-scale and community-sampled design to support dimensional research.\footnote{\cite{hbn_transdiagnostic_2017}.}
    \item \textbf{EEG + eye tracking paradigms (2017):} Provides tasks including steady-state and contrast decision tasks supporting developmental brain investigations.\footnote{\cite{eeg_eye_tracking_2017}.}
\end{itemize}

\subsection{Key Insights and Adaptations from Recent Methodologies}
\label{subsec:key-insights}

Based on these resources, this project adopts the following practical principles:
\begin{itemize}
    \item \textbf{Event-locked trial construction is critical:} prestimulus prediction requires careful alignment between events, EEG windows, and behavioral labels.
    \item \textbf{Verification before prediction:} steady-state characteristics should be validated (e.g., via SNR spectra) to ensure that extracted features correspond to measurable signal properties.
    \item \textbf{Target-specific evaluation:} regression and classification require different metrics and error analyses; reporting should be consistent across runs.
    \item \textbf{Reproducibility as a software requirement:} pipeline parameters, dataset filters, and split strategies should be explicit to avoid misleading comparisons.
\end{itemize}

\section{Positioning of This Work}
\label{sec:positioning}

This project uses HBN-EEG to study a focused research question: whether prestimulus EEG contains predictive information about behavioral performance. We model two outcomes: reaction time (RT) as a regression target and trial correctness (accuracy) as a binary classification target.

We evaluate this question in the Contrast Change Detection (CCD) task, where periodic visual stimulation during the rest period between trials supports steady-state feature extraction. By restricting inputs to a fixed 2-second prestimulus window, the modeling setting is intentionally constrained and emphasizes signal validation (via SNR spectra) and reproducible evaluation.

\subsection{CCD Experimental Design}
\label{subsec:ccd-experimental-design}

The CCD paradigm used in this study follows a structured visual stimulation and response protocol.

\textbf{Stimuli and visual setup:}
Subjects view a continuously flickering annular stimulus (1$^{\circ}$--6$^{\circ}$ visual angle) composed of two overlaid gratings:
\begin{itemize}
    \item Left-tilted grating ($-45^{\circ}$): flickers at 20 Hz
    \item Right-tilted grating ($+45^{\circ}$): flickers at 25 Hz
\end{itemize}
At baseline, both gratings are presented at 50\% contrast.

\textbf{Target events:}
On each trial, one grating increases linearly to 100\% contrast while the other simultaneously decreases to 0\%. The contrast-change period lasts 1.6 s, followed by a 0.8 s return-to-baseline period. Targets are presented with an inter-target interval of 2.8 s, 4.4 s, or 6 s.

Participants respond using left-hand click for left-tilted contrast increase and right-hand click for right-tilted contrast increase.
