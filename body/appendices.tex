\newappendix{Reproducibility Summary}

This appendix summarizes the fixed workflow and evaluation protocol used throughout the project.

\section*{A.1 Data and Task Scope}
\begin{itemize}
    \item Dataset context: HBN-EEG, Contrast Change Detection (CCD) task.
    \item Modeling window: fixed 2-second prestimulus inter-trial interval (ITI).
    \item Targets: reaction time (regression) and trial correctness (binary classification).
\end{itemize}

\section*{A.2 Fixed Processing Stages}
The operational pipeline used in this report is:
\begin{enumerate}
    \item Ingestion (load runs, events, and metadata)
    \item Trial construction (ITI extraction and label attachment)
    \item Preprocessing (filtering/normalization/artifact mitigation)
    \item Verification (SNR and related signal checks)
    \item Feature construction
    \item Modeling (regression and classification)
    \item Evaluation and artifact export
\end{enumerate}

\section*{A.3 Evaluation Metrics}
\begin{itemize}
    \item Regression: MAE, RMSE, R\textsuperscript{2}, Pearson correlation.
    \item Classification: accuracy, balanced accuracy, sensitivity, specificity.
\end{itemize}
